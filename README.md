# 안심노트 — 문자 접수 화면

의심 문자 분석 서비스의 1~3단계(문자 접수, 분석 정보 정리, 규칙 기반 위험 징후 분석)를 구현한 파이썬 웹 앱입니다.

## 실행

Python 3.10 이상에서 프로젝트 폴더로 이동한 뒤 실행합니다.

```powershell
python app.py
```

브라우저에서 http://127.0.0.1:8000 을 엽니다. `Ctrl+C`로 서버를 종료합니다.

Windows에서는 `run_app.bat`을 더블클릭해 실행할 수 있습니다. 설치된 Python 또는 Codex에 포함된 Python 런타임으로 별도 서버 창에서 앱을 시작하고, 8000번 포트가 열릴 때까지 기다린 다음 브라우저를 엽니다. 서버 창을 닫으면 앱이 종료됩니다.

## Vercel 배포

저장소를 Vercel 프로젝트에 연결하면 `/`에서 입력 화면을 제공하고 `/api/submit` Python 함수가 분석 결과를 반환합니다. 현재 평판 확인은 시연용 로컬 모의 데이터이며, 실제 URL 평판 서비스와 연결되어 있지 않습니다.

## 현재 구현 범위

- 의심 문자 본문 입력 및 5,000자 제한
- URL과 도메인 후보, 기관·서비스명, 의심 표현, 전화번호 후보 추출
- URL 형태와 본문 표현을 바탕으로 위험 징후 수준 및 판단 근거 표시
- 사용자용 결과를 판정·근거·권장 행동으로 요약하고, 상세 기술 정보는 접어서 표시
- 일부 공공기관 공식 도메인 대조와 URL 단축 서비스 확인
- 서버 메모리에서 처리하고 문자 내용을 저장하지 않음
- 링크를 자동으로 열지 않으며, 결과의 URL을 비활성 텍스트로 표시
- 로컬 모의 URL 평판 서비스가 지정된 시연 주소의 등록 여부를 반환하며, 실제 외부 서비스는 연결하지 않음
- 사용자 인증, 데이터베이스 저장, 카카오톡 알림은 아직 연결하지 않음

위험 징후 수준은 규칙을 설명하기 위한 참고 결과입니다. 공식 도메인 목록이 일부 기관에 한정되어 있고, 새로운 공격 방식은 놓칠 수 있으므로 실제 피싱 여부를 확정하지 않습니다. 평판 결과는 `reputation.py`에 있는 고정 시연 데이터이며 실제 위협 정보가 아닙니다.

테스트 주소는 사이트 UI에 포함하지 않습니다. 외부에서 직접 붙여 넣어 확인할 때는 문서용 예약 도메인 `example.com` 또는 RFC 5737 TEST-NET-2 예약 IP를 사용할 수 있습니다. 위험 징후 예시는 실제 악성 사이트가 아니라 URL 모양을 보여주는 시뮬레이션이어야 합니다.

외부 공개 전에는 인증, HTTPS, 개인정보 처리 방침과 안전한 저장·삭제 정책을 설계해야 합니다.
